## 📋 Prehľad projektu

Tento repozitár slúži ako **kolekcia základných QA artefaktov**, šablón a príkladov pre **manuálne testovanie softvéru**. Projekt demonštruje silné pochopenie metodiky a dokumentačných štandardov, ktoré tvoria základ pre akýkoľvek úspešný testovací cyklus (vrátane automatizácie).

### Prečo je tento repozitár dôležitý?

* **Štruktúra:** Ukazuje schopnosť písať prehľadné, štandardizované a udržateľné testovacie dokumenty.
* **Základy pre Automatizáciu:** Poskytuje pevné manuálne základy, ktoré slúžia ako vstup pre vývoj End-to-End (E2E) automatizačných testov.

## 🎯 Obsah repozitára (Testovacie artefakty)

Repozitár obsahuje príklady dokumentácie a šablóny zamerané na rôzne domény:

| Artefakt | Popis |
| :--- | :--- |
| **Test Cases** | Detailné, krokové scenáre overovania funkčnosti (napr. na úrovni používateľského rozhrania). |
| **Test Scenarios** | Široké, vysokoúrovňové testovacie toky (napr. nákupný proces, prihlásenie). |
| **Bug Reports** | Šablóny pre profesionálny report chýb s prvkami ako je *Steps to Reproduce*, *Expected/Actual Results* a *Severity*. |
| **Test Checklists** | Príklady kontrolných zoznamov pre regresné alebo exploračné testovanie. |

## 🌐 Príklady testov (Cieľové aplikácie)

Príklady sú vytvorené na základe rôznorodých domén, aby demonštrovali univerzálnosť metodiky:

* **E-commerce:** Príklady pre populárne e-shopy (ako je **Alza**).
* **Finančné služby:** Scenáre pre testovanie funkcionality bankových systémov.
* **Vzdelávacie platformy:** Testovacie prípady pre platformy ako **Douč ma**.
