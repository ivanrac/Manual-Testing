# Medirex Registration Testing

## Projekt

Manuálne testovanie registračného formulára na stránke Medirex.

Cieľom projektu bolo precvičiť si manuálne testovanie webových formulárov, návrh testovacích scenárov, tvorbu testovacích prípadov a využitie základných ISTQB techník návrhu testov.

## Rozsah testovania

Testované oblasti:

- Registrácia používateľa
- Validácia e-mailovej adresy
- Validácia mena a priezviska
- Validácia rodného čísla
- Povinné polia formulára
- Chybové hlášky
- Správanie formulára pri neplatných vstupoch

## Použité techniky

- Ekvivalenčné triedy
- Analýza hraničných hodnôt
- Odhad chýb
- Pozitívne testy
- Negatívne testy
- Explorátivne testovanie

## Výstupy

- Test scenáre
- Test cases
- Screenshoty
- Pozorovania počas testovania

## Použité prostredie

- Windows 11
- Google Chrome
- Mozilla Firefox
